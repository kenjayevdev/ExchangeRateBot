# 💰 ExchangeRateBot

🛠The following technologies were used in this project: Python aiogram, sqlite3, Admin Panel✅

📝 Brief information:
💡With this 🤖Bot, you can track the 📊 rates of 💰Dollar 💶Euro 💸Ruble and 5 countries bordering Uzbekistan✅

## Setup

- run `git clone https://github.com/kenjayevdev/ExchangeRateBot.git` copy repositories
- run `cd ExchangeRateBot` accessing repositories
- run `python -m venv env` to create virtual environment
- run `env\Scripts\activate` to activate the env
- run `pip install -r requirements.txt` to install all required packages
- Create a .env file and set ADMINS=#Telegram user ID and BOT_TOKEN=#BOT API KEY.
- run `python app.py`
